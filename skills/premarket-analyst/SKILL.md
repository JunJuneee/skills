# Premarket Analyst — 프리마켓 분석

## 트리거 조건

- 사용자가 "프리마켓", "장전", "시간외" 키워드 + 분석 요청
- 08:00~09:00 시간대 (장 시작 전 동시호가)
- "/premarket-analyst" 명령

## 한국 시장 프리마켓 구조

| 시간 | 단계 | 상태 |
|---|---|---|
| 08:00~08:30 | 장전 시간외 단일가 | 거의 비활성 |
| **08:30~09:00** | **정규장 동시호가** | 예상체결가 활성 ⭐ |
| 09:00 | 정규장 시작 | 시초가 결정 |
| 15:30 | 정규장 마감 | - |
| 15:40~16:00 | 장후 시간외 종가 | - |
| 16:00~18:00 | 시간외 단일가 | - |

**예상체결가는 08:30 이후 활성화**. 8시대는 호가 거의 형성 안 됨.

## KIS API 활용

### 1. 예상체결가 (호가/예상체결)
- `inquire-asking-price-exp-ccn` (TR: FHKST01010200)
- output2의 `antc_cnpr` (예상체결가), `antc_cntg_vrss_rate` (등락률), `antc_vol` (예상량)

### 2. 예상체결 상승/하락 상위
- `exp-trans-updown` (TR: FHPST01820000)
- `fid_rank_sort_cls_code`: 0=상승률, 3=하락률
- `fid_mkop_cls_code`: 0=장전예상, 1=장마감예상

## 4가지 분석

### 1️⃣ 보유 + Watchlist 예상체결
```
종목                    예상가      전일대비    예상량
SK하이닉스 ⭐           2,150,000    -3.50%   192,000  🔴
PLUS HBM ⭐              115,000    -2.80%    48,000  🟡
한화에어로 ⚡           1,100,000    +5.20%    34,000  🚀
...
```

### 2️⃣ 시장 급등 TOP15
- 전체 시장 예상 상승률 상위

### 3️⃣ 시장 급락 TOP15
- 전체 시장 예상 하락률 상위
- **인버스 ETF 폭락** = 시장 폭등 신호
- **레버리지 ETF 폭락** = 해당 종목 폭락 신호

### 4️⃣ 매크로 컨텍스트 (Step 4.7)
- 미국 시장 마감 (NVDA, SMH, MU)
- 마이크론 = 한국 반도체 프록시
- 한국 야간 선물 (가능 시)

## 시그널 해석

### 시장 방향
| 신호 | 의미 |
|---|---|
| 인버스 ETF -30% | 시장 폭등 가능 |
| 레버리지 ETF -30% | 시장 폭락 가능 |
| 다수 종목 동조 +30% | 강세 분위기 |
| 다수 종목 동조 -30% | 패닉 매도 |

### 갭 종류 (chart-analyst v1.6)
- **소멸 갭**: 상승 마지막 갭 + 추세 실패 = 동력 소진
- **이탈 갭**: 추세 시작 = 신추세
- **이탈 갭**: 추세 중간 = 가속
- **일반 갭**: 횡보 = 곧 채워짐

## 시간대별 권장

| 시간 | 조치 |
|---|---|
| 08:00~08:30 | 호가 부족 → 분석 의미 적음 |
| 08:30~08:55 | ⭐ 최적 분석 시점 (동시호가 활발) |

| 09:00 정각 | 정규장 시작 = 시초가 확인 |

[종목/예상가/등락률/체결량]

🔻 시장 하락률 TOP15
[종목/예상가/등락률/체결량]

## 주의사항

- ⚠️ 8시 30분 이전 호가는 의미 적음 (거래량 0)
- ⚠️ 예상체결가 ≠ 실제 시초가 (변동 가능)
- ⚠️ 만기일 (6/11 등) 변동성 극대 → 예상체결도 부정확
- ⚠️ 한국 야간 선물 데이터 KIS API에 없음 (KRX 별도)
- ⚠️ 토요일/일요일 호출 비효율

## 매크로 바로미터 (Step 4.7)

| S&P500 | 전체 시장 |
| DXY | 환율/금리 |

장 시작 전 시초가 갭다운/갭업 예상 + 매수/매도 의사결정 빠르게.

## How to apply

08:30 이후 호출 → KIS API 예상체결 + 시장 급등락 + 매크로 = 시초가 예측.
