# Post checklist

- Current facts verified with authoritative sources
- User title and intended content preserved
- First image placed before Table of Contents
- All supplied images embedded and captioned
- Exact requested attribution preserved
- Table of Contents anchors work
- Tables scroll horizontally on mobile
- One prominent official action URI included
- Official references linked directly
- FAQ, summary, and disclaimer included when appropriate
- Relevant Blogger labels set
- Public URL returned
- Public HTML contains expected image count, TOC, URI, and required text
