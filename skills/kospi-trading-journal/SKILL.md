# Korean Trend Trading Journal

## 원칙

- 한국 주식 가격은 KIS API를 우선 사용한다.
- 현재가와 최신 확정 일봉의 날짜를 구분한다. 장 시작 전에는 전일 확정봉임을 명시한다.
- 실제 주문은 사용자가 명시적으로 요청하고 주문 직전 확인 절차가 끝난 경우가 아니면 실행하지 않는다.
- 기본 계좌는 사용자가 정한 1억원, 거래당 최대 손실은 1%인 100만원이다. 사용자가 새 값을 지정하면 그 값을 우선한다.
- 분석 숫자는 실제 KIS 체결가가 바뀔 때 다시 계산한다.

## 작업 순서

1. KIS 국내주식 현재가와 최소 100일 일봉을 조회한다. MA200 분석이 필요하면 16개월을 페이지네이션한다.
2. 데이터 기준 시각, 현재가, OHLCV, 최근 수익률을 확인한다.
3. EMA5·20·40, 3 MACD, ATR20, MA20·50·200, RSI14, 거래량 평균을 계산한다.
4. 국면·띠 간격·이격·모멘텀·지지·저항·변동성을 교차 검증한다.
5. 진입을 제안할 때 눌림 매수와 돌파 매수를 반드시 별도 전략으로 계산한다.
6. 수량, 최대 손실, 손절, 트레일링, 수익 확정, 추가 조건을 수치화한다.
7. 기록 요청이면 Obsidian에 종목명만으로 저장한다.
8. 웹 반영 요청이면 기존 Stock Trading 웹을 수정·빌드·비공개 배포한다.

상세 계산과 판정 기준은 [references/trading-rules.md](references/trading-rules.md)를 읽는다.  
Obsidian 기록을 만들거나 수정할 때는 [references/journal-template.md](references/journal-template.md)를 읽는다.

## 응답 규칙

- 결과를 먼저 말하고 근거를 뒤에 둔다.
- 저항은 단일 숫자보다 반복 고점이 모인 가격대로 표현하고, 날짜별 거부 근거를 제시한다.
- `위`, `이상`, `이하`, `이탈`을 엄격히 구분한다. 종가가 돌파 기준과 같으면 “위 종가” 조건은 미충족이다.
- EMA5를 장중 이탈한 뒤 양봉 종가로 회복하면 눌림 지지 조건 후보로 인정하되, 돌파 조건과 구분한다.
- 거래량 돌파는 현재 거래량과 20일 평균을 함께 표시한다.
- ATR 비율이 높거나 유동성이 낮으면 계산상 최대수량보다 유닛과 최대 포지션을 줄인다.
- 사용자가 일지 작성을 요청하면 저장 후 문서 구조를 다시 읽어 검증한다.

## 웹 반영

- 사용자가 웹 표시를 원하거나 기존 대화에서 웹 일지 동기화를 요구한 경우에만 반영한다.
- 기존 `.openai/hosting.json`의 프로젝트 ID를 재사용하고 Sites 빌드·호스팅 스킬을 따른다.
- 종목 선택 시에만 접이식 `금융 / 매매일지` 패널을 표시한다.
- 웹 규칙도 눌림 매수와 돌파 매수를 서로 다른 카드/섹션으로 보여준다.
- 프로덕션 빌드 성공 후 기존 비공개 URL에 새 버전을 배포한다.
