# 한국 증시 마감 숏츠 자동 제작·발행

market-note-shorts 스킬을 사용해 오늘 한국 증시 마감 숏츠를 만들고 유튜브와 인스타그램에 발행한다.
사람 확인 없이 끝까지 진행한다. 중간에 질문하지 말고 판단해서 진행한다.

## 대상
오늘(KST 기준) 정규장 마감. 휴장일이면 아무것도 만들지 말고 "휴장"만 보고하고 종료한다.

## 절차
1. 데이터 수집·검증
   - 네이버 증권 API로 KOSPI·KOSDAQ 종가와 등락률, 시가·장중 저점·고점
   - 투자자별 매매동향(개인/외국인/기관계/기타법인) — 합계가 0이 되는지 확인해 컬럼 매핑을 검증
   - 시가총액 상위와 급등·급락 종목, 전일 대비 특징주
   - 배경 뉴스는 웹 검색으로 확인. 확인되지 않은 원인은 절대 서술하지 않는다.
   - 모든 수치는 최소 2개 경로로 교차 확인한다. 소스마다 기준이 달라 엇갈리는 항목(유가·금 등)은 사용하지 않는다.
2. 원고
   - 디스플레이 원고와 TTS 원고를 따로 만든다. TTS는 references/script-style.md 규칙을 따르고 단위는 `프로`로 읽는다.
   - 카드 순서와 내레이션 순서를 일치시킨다.
3. 카드
   - Remotion 프로젝트 /Users/jun/Documents/ChatGPT/금융 쇼츠 제작/remotion-shorts 에
     KoreaMarketCardsYYYYMMDD.tsx 를 만든다. 직전 회차 파일을 그대로 본떠 스타일을 유지한다.
   - 8개 씬 + 책임면책고시(scene 8). 중요한 텍스트는 x=864 왼쪽에 둔다.
   - 오프닝 카드에 해당 장 날짜를 `YYYY.MM.DD · 한국 증시` 형태로 넣는다. 이 카드가 커버로 쓰인다.
   - 오프닝 프레임을 assets/thumbnail-... 로 내보내고, 인스타 커버는 기본값(프레임 0)을 그대로 쓴다.
4. 음성·타이밍
   - scripts/synthesize_tts.mjs 로 합성 (기본값 그대로, voice 8yL2rVx40vjDeu5pTbg6)
   - uv run --with faster-whisper python scripts/analyze_tts.py 로 타이밍 분석
   - 씬 경계는 앞 문장 끝과 다음 문장 시작 사이 침묵의 중간점. build_timeline.py 로 프레임 계산
5. 렌더·검증
   - KoreaMarketVideoYYYYMMDD.tsx 를 만들고 Root.tsx 에 등록해 렌더
   - verify_video.py 로 검증. 씬 전환 직후 스틸을 뽑아 카드 순서와 잘림을 눈으로 확인
6. 아카이브
   - /Users/jun/Desktop/github/ai_video/korea/YYYY-MM-DD/ 아래 video, audio, assets, qa, scripts 로 정리
7. 발행
   - 발행 전에 인스타 계정 최근 게시물을 조회해 같은 날짜 영상이 이미 있으면 중복 발행하지 않는다.
   - 유튜브: youtube_upload_video.py 로 공개 업로드
   - 인스타: instagram-reels-publisher 스킬 사용. GitHub 릴리스로 임시 스테이징 후 발행하고 릴리스는 반드시 삭제한다.

## 실행 규칙

이 작업은 사람이 없는 헤드리스 실행이다. 응답을 끝내는 순간 프로세스가 종료되고 실행 중이던
작업도 함께 죽는다. 다음을 반드시 지킨다.

- **작업이 남은 채로 턴을 끝내지 않는다.** "지금 렌더 중입니다", "완료되면 이어서 진행하겠습니다"
  같은 보고로 응답을 마치면 그 시점에 파이프라인이 중단된다. 마지막 줄에 RESULT 를 출력한 뒤에만
  응답을 끝낸다.
- **오래 걸리는 단계는 포그라운드로 돌리고 타임아웃을 명시한다.** Remotion 렌더는 3분 이상
  걸리므로 Bash 호출에 timeout 을 900000(15분) 이상으로 준다. `&` 나 백그라운드 실행을 쓰지
  않는다. 렌더가 끝나 파일이 생긴 것을 확인한 뒤 다음 단계로 넘어간다.
- **이어받기.** 시작 전에 오늘 날짜의 아카이브와 Remotion 프로젝트를 확인한다. 원고·카드·음성·
  타이밍·영상 중 이미 만들어진 것이 있으면 다시 만들지 말고 없는 단계부터 이어서 진행한다.
  직전 실행이 중간에 끊겼을 수 있다.
