# Chart Analysis Framework (차트 분석 기법)

> v1.7 (70개 방송 전수 검증 완료, 2024-12 ~ 2026-02). 매 분석 시 이 프레임워크를 따른다.

## 트리거 조건

- 사용자가 자산명 + "차트 분석", "기술적 분석", "지금 어때?" 요청
- `/chart-analyst BTC`, `/chart-analyst 삼성전자` 형태로 호출
- `financial-analyst`가 펀더멘털이라면, 이 스킬은 기술적 분석 전용

## 데이터 소스 원칙

- **한국 주식**: `FinanceDataReader (FDR)` 우선 — pykrx는 KRX 서버 장애 시 JSONDecodeError 발생
  ```python
  import FinanceDataReader as fdr
  df = fdr.DataReader('티커코드', 'YYYY-MM-DD', 'YYYY-MM-DD')
  # 컬럼: Open, High, Low, Close, Volume, Change
  ```
  - **조회 기간**: 현재일 기준 **16개월 전**부터 — MA200(~10개월) 계산 여유 확보
  - pykrx는 KRX 서버 복구 시 대체 가능하나, FDR이 기본
  - WebSearch/WebFetch 불필요 (Bash로 직접 계산)
- **미국 주식**: Yahoo Finance / TradingView (한국 종목은 TradingView 배당 보정 왜곡 주의)
- **크립토**: Binance / Upbit / CoinMarketCap
- **선물/지수/환율**: Investing.com / TradingView

## 2. 분석 프레임워크 (5단계)

### Step 1: 가격 현황 (Price Snapshot)
- 현재가, 24h 변동률, 시가총액
- 52주 최고/최저 대비 위치
- 최근 1주/1개월/3개월 수익률

### Step 2: 추세 분석 (Trend Analysis)
- **이동평균선 (MA)**: 20일(단기), 50일(중기), 200일(장기)
- **골든크로스/데드크로스**: 50일 MA와 200일 MA 교차 확인
- **가격 vs MA 위치** / **MA 기울기**: 상승/하락/횡보
- **추세선 분석 (Trendline)** — v1.2
  - 추세선 접촉 횟수 ↑ = 신뢰도 ↑
  - 추세선 "자꾸 건드림" = 이탈 임박 (약세 신호)
  - ATH에서도 상단 추세선에 걸리면 조정 가능
  - **반복 추세선 접촉 = 복합 저항 강화** — v1.6: 2+회 거부 시 저항 약화 아닌 강화. "트랩 = 즉시 매도" 규칙 적용
- **거래량 분석** (v1.1)
  - 상승 시 거래량 증가 → 강세 / 감소 → 반등 의심
  - 하락 시 거래량 급증 → 패닉셀 가능
  - **지지선 대량거래 = 최악 신호** — v1.6: 지지 이탈 + 폭발적 거래량 = 기관 분배 완료, 회복 극히 어려움
  - **돌파 거래량 적정 범위** — v1.6: 과소(확신 부족)도, 과다(분배)도 부정적. "적절히" 증가가 최선
- **음봉 빈도 분석** — v1.2
- **수렴형 상승 = 약세 신호** — v1.6: 가격 상승 중 고저점 수렴 = 에너지 소진 경고

### Step 2.5: 돌파 확인 기법 — v1.6 추가

**4H 봉 종가 기준 확인법:**
- 장중 레벨 터치 ≠ 돌파. **4시간봉 종가가 레벨 위/아래 마감해야** 유효
- 종가 미돌파 = 거짓돌파 (wick만 찍은 것)

**틱차트→1분→5분 캐스케이드 확인:**
- 전환점에서 틱차트가 먼저 꺾임 → 1분 → 5분 순차 전파
- 모든 타임프레임 꺾임 = 방향 전환 기정사실

### Step 3: 모멘텀 지표 (Momentum Indicators)
- **RSI (14일)**: 70+ 과매수, 30- 과매도, 다이버전스 주시
- **MACD**: 시그널선 교차, 히스토그램, 제로라인
- **VIX 20 경계선** — v1.6: 20 이하=안정, 20 돌파=경계, 30+=패닉

### Step 4: 지지/저항 분석 (Support & Resistance)
- 주요 지지/저항선 (최소 3개) + 구체적 가격 타겟 (v1.2)
- 피보나치 되돌림 레벨 (38.2%, 50%, 61.8%)
- **조정 타겟 3단계** — v1.2: 최소/적정/최대
- **저항 밀도 분석** — v1.6: 좁은 가격대에 고점 다수 포진 = 돌파 난이도 급등
- **다중 바닥 (Multiple Bottom)** — v1.6: 같은 레벨 다수 테스트 = 단단한 바닥, 돌파 시 강력

### Step 4.1: 갭 분석 — v1.6 추가

| 갭 유형 | 의미 | 대응 |
|---------|------|------|
| **소멸 갭 (Exhaustion Gap)** | 상승 마지막 갭 + 추세 실패 = 동력 소진 | 중립→매도 |
| **갭+전고점 복합 저항** | 갭 상승 착지점이 전고점과 겹침 = 매도 강화 | 진입 자제 |
| **갭 구간 지지/저항** | 갭 발생 구간 = 모든 자산에서 강력 S/R | 자동 레벨 등록 |
| **고점 매물 포진** | 다수 역사적 고점 밀집 = 대량 거래 필요 | 재료 없이 연타 돌파 어려움 |

### Step 4.2: 패턴 분석 — v1.6 추가

| 패턴 | 특징 | 판단 |
|------|------|------|
| **마름모 (Diamond)** | 확장→수축, higher low 근처 고점 형성 | V반등보다 우수한 바닥, 시간 소요 큼 |
| **하반경직 필터** | 수차례 하방 이탈 시도 실패 확인 | 확인 후에만 반등 매수 진입 |
| **언더슈팅** | 추세선 일시 하향 돌파 후 즉각 복귀 | 오버슈팅의 하방 대칭, 추세 파괴 아님 |
| **쌍 트랩** | 같은 방향 트랩 2회 연속 | 단일 트랩보다 강한 반전 신호 |
| **가격 트랩** | 전저점 미세 이탈 후 즉시 반등 | 손절 유발용 의도적 트랩 |

### Step 4.4: 크립토 에너지 분석 (Crypto Energy) — v1.5, v1.6 보강

| 차트 | 의미 | 확인 사항 |
|------|------|-----------|
| **BTC 도미넌스** | BTC 점유율 | 상승=알트약세, 하락=알트강세 |
| **Total 1** (전체) | 전체 시총 | 에너지 방향, 저항선 |
| **Total 2** (BTC 제외) | 알트 건강도 | Total 1보다 약하면 알트 부진 |
| **Total 3** (BTC+ETH 제외) | 소형 알트 | 가장 약하면 소형 회피 |
| **OTHERS** (v1.6) | BTC+ETH 제외 순수 소형 알트 | Total3보다 강하면 소형 알트 주도 |

**크립토 원화 분석 — v1.6:**
- **원화 차트 독립 분석**: 원화 약세 + 김프 = 달러 차트와 구조적 디커플링
- **김프 이론가**: (USD 가격/oz) × 환율 × 28.35/1000 = KRW/kg 이론가. 실거래가와 비교해 프리미엄 판단
- **김프 빠짐 = 국내 수요 약화**: 프리미엄 급락 = 국내 매도 압력
- **급격한 원화 강세 → BTC-KRW 지체**: BTC-USD 상승해도 BTC-KRW 횡보 가능
- **코인베이스 역산법**: COIN 주가 하락률 → BTC 예상 하락률 추정 (proxy)

### Step 4.5: 수급 분석 (Supply/Demand Flow) — v1.1, v1.6 보강
- **한국주식**: 외국인/기관/개인 순매수 동향
- **개인 역사적 순매도 = 비상투** — v1.6: 개인 3조+ 순매도 + 외국인 흡수 = 상투 아님
- **외국인/기관 대량매도 + 개인 패닉매수 = 상투 확인** — v1.6: 반대 방향도 적용
- **신용잔고 폭증 = 시스템 리스크** — v1.6: 신용잔고 29조+ 급등 시 리스크 관리 구간
- **바텀업 시장 분석** — v1.6: 구성 종목 건강도 집계 → 지수 방향 예측 (시총 가중)

### Step 4.6: 핵심 종목 영향력 (Market Mover) — v1.1, v1.6 보강
- NVDA/TSLA 실적/뉴스 → 시장 방향
- **삼성전자 → KOSPI 매핑** (v1.3)
- **마이크론 → 한국 반도체 프록시** — v1.6: 마이크론 after-hours 실적 = 하이닉스/삼전 익일 갭 추정
- **코스피200 vs 코스피 괴리** — v1.6: 200 신고가 + 종합 정체 = 소수 대형주 편중 (시장 폭 취약)
- **대형주→잡주 장세 전환** — v1.6: 대형주 횡보 + 중소형 순환매 급등 = 후기 사이클 신호
- **KOSPI 목표 달성 → 코스닥 디커플링** — v1.6: KOSPI 조정 중에도 코스닥 독립 랠리 가능
- **ETF 자동매수 왜곡** — v1.6: 코스닥 ETF 유입 시 시총 상위 종목 기계적 매수 → 차트 시그널 신뢰도 할인
- **섹터 시소 로테이션** (v1.5)

### Step 4.7: 매크로 바로미터 자산 — v1.3, v1.6 보강

| 바로미터 자산 | 시그널 | 의미 |

- 동조화 회복 = 안도 신호

### Step 5: 종합 판단 (Verdict)
- **방향**: 강세 / 약세 / 중립
- **신뢰도**: 높음 / 중간 / 낮음
- **포지션 레짐**: 롱 only / 숏 only / 양방향 / 관망
- **조정 유형**: 가격조정 / 기간조정 / 복합
- **확률 표현** — v1.6: 51:49 등 정량적 bias 표현, 시간 경과에 따라 확률 비율 전환
- **근거 요약**: 3줄 이내
- **주의사항**: 리스크 요인

### 3.05 ATH 트랩 판별 — v1.2

| 조건 | 건강한 ATH 돌파 | 트랩 가능성 |
|------|-----------------|-------------|
| 상단 추세선 | 여유 상방 | 추세선에 걸림 |

### 3.06 추세선 트랩 — v1.3
돌파 후 즉시 되돌림 = 트랩. 하루 더 지켜본 후 재돌파 여부 확인.

### 3.07 기간조정 vs 가격조정 — v1.3
- 강세장 조정 = 대부분 기간조정 → 숏 금지, 롱 홀딩
- 기간조정: 2~4주, 섹터 로테이션 빈번
- **배당락/연초 효과** — v1.6: 연말 매도 없었으면 연초 효과도 무효 (조건부 계절성)

### 3.08 포지션 레짐 — v1.3
롱only / 숏only / 양방향 / 관망 + **방향성 상실 = 거래 회피** (v1.5)

### 3.09 종목 등급 A/B — v1.4
왼쪽 저점 사수 = A급(적극), 이탈 = B급(소극)

### 3.10 되돌림 추세선 — v1.4
하락 추세 반등 한계 측정. 돌파 = 전환 후보, 저항 = 하락 지속.

### 3.11 모도리 vs 본격 상승 — v1.4, v1.6 보강
- **신고 모돌이** — v1.6: 전고점 초과 후 되돌림 = 쌍봉 완성 → 대형 상투 경계
- 기존 단순 모돌이와 구분 필수

### 3.12 안갈이 — v1.4
강한 저항 횡보. 기간조정과 다름 (원인 = 저항, 결과 불확실).

### 3.13 수확 타이밍 — v1.4
밑바닥 매수자 = 익절, 뒤늦은 진입자 = 추격 금지.

### 3.14 에너지 고갈 vs 힘 부족 — v1.6 추가

| 구분 | 힘 부족 (Force Deficit) | 에너지 고갈 (Energy Collapse) |
|------|------------------------|------------------------------|
