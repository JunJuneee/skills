# Portfolio Analyst — chart-analyst v1.8 기반

## ⭐ 핵심 원칙

**점수 시스템 사용 금지.** chart-analyst v1.8 5단계 + 종합 판단 매트릭스만 사용.

v1.8은 70개 방송 + 2,482개 예측 검증된 프레임워크. 임의 bull/bear 가중치보다 신뢰도 높음.

## 트리거

- "포트폴리오 분석", "포트폴리오 정리", "포트폴리오 확인"
- "오늘 포트폴리오", "내 포트폴리오"

## 5단계 프레임워크 (각 종목)

**Step 1: 가격 현황**
- 현재가, 일간 변동
- 1주/1개월/3개월/YTD
- 52주 위치
- 손익률

**Step 2: 추세 분석**
- MA20, MA50, MA200
- 골든/데드크로스
- 거래량 (상승 시 증가 = 강세)
- 음봉 빈도 (20일)

**Step 3: 모멘텀**
- RSI(14): 70+/30-
- MACD: 교차, Hist

**Step 4: 지지/저항**
- 지지/저항 3개+
- 피보나치 38.2/50/61.8%
- 갭 분석
- ATH 트랩 (52주 95%+ 시)

**Step 5: 종합 판단** ⭐
- 방향 (강세/약세/중립)
- 신뢰도 (높음/중간/낮음)
- 포지션 레짐 (롱only/숏only/양방향/관망)
- 조정 유형 (가격/기간/복합)
- 확률 (70:30 등)
- 종목 등급 (A/B)
- 근거 3줄

## v1.8 종합 판단 매트릭스

| 조건 | 강세 | 약세 |
|------|------|------|
| 가격 vs 200MA | 위 | 아래 |
| 50MA vs 200MA | 골든크로스 | 데드크로스 |
| RSI | 30~50 반등 | 70+ 하락 |
| MACD | 상향돌파 | 하향돌파 |
| 거래량 | 상승 시 증가 | 하락 시 증가 |
| 추세선 | 지지 유지 | 이탈/저항 걸림 |
| 음봉 빈도 | 양봉 위주 | 잦음 |
| 국채 금리 | 하락 | 상승 |
