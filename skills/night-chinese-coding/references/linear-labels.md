# Linear 라벨 사용법 — Jay's workplace

> 팀: `Jay's workplace` (JAY) · Composio 계정: `homeshopick`
> 상태 흐름: `Backlog → Todo → In Progress → In Review → Done` (+ Canceled, Duplicate)

## 1. 에이전트 실행 제어 라벨

에이전트(Traycer/Claude/Codex)가 이슈를 처리할 때 부착·제거하는 라벨. **야간 자동 실행의 제외 필터**로도 사용된다.

| 라벨 | 의미 | 부착 시점 | 제거 시점 | 야간 자동실행 |
|------|------|-----------|-----------|:---:|
| `agent-running` | 에이전트가 현재 작업 중 | 착수 시 | 완료·보류 시 | ❌ 제외 |
| `agent-hold` | 에이전트 작업 보류 지시 | 사람이 보류 지시 시 | 보류 해제 시 | ❌ 제외 |
| `agent-decided` | 에이전트가 판단·결정 완료 | 에이전트 결정 완료 시 | 사람이 후속 처리 시 | ✅ 가능 |
| `owner-action` | 오너(사람)의 직접 액션 필요 | 사람 개입이 필요할 때 | 사람 액션 완료 시 | ❌ 제외 |
| `blocked` | 외부 요인으로 차단 | 차단 발생 시 | 차단 해제 시 | ❌ 제외 |
| `needs-confirm` | 확인·승인 필요 | 확인이 필요할 때 | 확인 완료 시 | ❌ 제외 |

### 사용 예시 (실제 이슈)

```
JAY-604 | In Progress | [기능 · 팝업 검색·챗, agent-running]
  → 에이전트가 현재 작업 중. 야간 자동실행이 중복 착수하지 않음.

JAY-531 | Todo | [agent-hold, owner-action, Feature, ...]
  → 보류 + 사람 액션 필요. 야간 자동실행 대상 아님.

JAY-638 | Done | [agent-decided]
  → 에이전트 판단 완료 후 Done.
```

## 2. 이슈 유형 라벨

| 라벨 | 용도 |
|------|------|
| `Feature` | 새 기능 추가 |
| `Bug` | 버그 수정 |
| `Improvement` | 기존 기능 개선·리팩토링 |

이슈당 **하나만** 부착. 유형이 불명확하면 생략 가능.

## 7. 야간 자동 실행 대상 판정 요약

```
대상 = 상태가 Todo
     AND 담당자가 Jay
     AND agent-running 없음
     AND agent-hold 없음
     AND blocked 없음
     AND needs-confirm 없음
     AND owner-action 없음
```

- 유형·도메인·기능·단계 라벨은 **선정에 영향 없음** (분류 전용)
- `analytics-daily`도 선정에 영향 없음
- 저녁에 이슈를 **Todo + Jay 담당**으로 등록하면 야간(22:00~08:00 KST)에 자동 실행
- 실행을 막으려면 `agent-hold` 또는 `blocked` 부착
