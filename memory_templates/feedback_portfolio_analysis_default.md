# 포트폴리오 분석 — chart-analyst v1.8 기준

## 🚫 금지

- 임의 점수 시스템 사용 금지 (bull/bear)
- 자체 시그널 등급 사용 금지
- v1.8과 다른 기준 적용 금지

## ✅ v1.8 5단계 프레임워크

각 종목마다:
- Step 1: 가격 현황
- Step 2: 추세 (MA + 거래량 + 음봉빈도)
- Step 3: 모멘텀 (RSI/MACD)
- Step 4: 지지/저항 (피보나치 + ATH 트랩)
- Step 5: 종합 판단 (방향/신뢰도/포지션레짐/등급/확률)

## v1.8 종합 판단 매트릭스

| 조건 | 강세 | 약세 |
|------|------|------|
| 가격 vs 200MA | 위 | 아래 |
| 50MA vs 200MA | 골든크로스 | 데드크로스 |
| RSI | 30~50 반등 | 70+ 하락 |
| MACD | 상향돌파 | 하향돌파 |
| 거래량 | 상승 시 증가 | 하락 시 증가 |
| 음봉 빈도 | 양봉 위주 | 잦음 |

## v1.8 메타 편향 (70개 방송 검증)

- 한국 반도체 매도 신호 신뢰도 매우 낮음
- 반도체 상투 편향 주의 (AI 슈퍼사이클)
- "상투" 3회 규칙
- 기술적 과매수 = 매도 편향 주의

## ATH 트랩 (52주 95%+)

거래량 감소 + RSI 70+ + 추세선 걸림 = 트랩 의심

## 자동 통합 4가지

1. 보유 (v1.8 5단계)
2. Watchlist (v1.8 5단계)
3. 외국인/기관 수급
4. 매크로 (마이크론 → 한국 반도체 프록시)

## 출력 표준

```
종목 (코드)
[Step 1] 가격/수익률/52주위치
[Step 2] 추세/MA/거래량
[Step 3] RSI/MACD
[Step 4] 지지/저항
[Step 5] 방향 + 신뢰도 + 확률 + 등급 + 포지션
         근거 3줄 / 트랩·편향 주의
```

**Why:** v1.8은 검증된 프레임워크. 임의 점수보다 신뢰도 높음.

**How to apply:** 포트폴리오 분석 → v1.8 5단계 + 매트릭스 적용 → 점수 시스템 금지.
