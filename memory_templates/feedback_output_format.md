# 출력 형식 — 단순 라인

표 형식은 한글+숫자 정렬 어긋남으로 가독성 떨어짐. 단순 라인 형식 사용.

## ✅ 단순 라인 패턴

```
🎯 [카테고리] (참조 정보)
  → [핵심값] ([변동률]) [이모지] [설명] — [세부]
  → [핵심값] ([변동률]) [이모지] [설명]
```

## 예시 — 저항선

```
🎯 저항선 (현재가 246,000)
  → 257,500 (+4.7%) 🔴 1차 벽 — 쌍봉
  → 285,000 (+16%)  🟡 매물대
  → 300,786 (+22%)  🟢 MA50
  → 318,500 (+29%)  🚀 5/7 고점
```

## 예시 — 시그널 분류

```
🟢 강세 (신뢰도 높음)
  → SK하이닉스   +144% | 정배열 | A급
  → 삼성전기     -0.05% | 정배열 | A급

🟡 약세
  → 현대건설    -17.58% | 역배열 | B급
```

## ❌ 표 사용 금지 (한글 포함 시)

```
| 종목 | 가격 | 변동 |  ← 한글 정렬 깨짐
```

## 단, 영문/숫자만 + 3컬럼 이하는 표 허용

**Why:** 한글 포함 표는 정렬 깨져 가독성 떨어짐.
**How to apply:** 모든 출력에서 표 → 단순 라인. 영문 표만 예외.
