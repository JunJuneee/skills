## 데이터 흐름

### 1. 수급 데이터
- **자동 수집** (auto_collect.py + launchd): KIS API → DB (가집계)
- **수동 입력** (manual_input.py): 토스 캡처 → DB (정산값)
- **분석** (portfolio_report.py): DB 조회 → 매칭 → 출력

### 2. 가격 데이터
- **실시간**: KIS API `inquire-price`
- **일봉**: FinanceDataReader (FDR)
- **백업**: FDR이 오늘 데이터 없으면 KIS 현재가로 보완

### 3. 기술 지표
- 모두 Python에서 계산
- RSI/MACD/MA — 표준 공식
- 점수 시스템 — 자체 정의 (bull-bear 가중치)

## 컴포넌트 책임

| 컴포넌트 | 책임 |
|---|---|
| **SKILL.md** | Claude 행동 규칙 정의 (트리거, 출력 형식) |
| **Memory** | 사용자 상태 (보유, 관심, 규칙) |
| **Python scripts** | 실제 데이터 처리 + 분석 |
| **DB** | 수급 데이터 누적 저장 |
| **launchd** | 자동화 트리거 (매일 18:00) |
